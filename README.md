# YaPB Docs

[![Deploy to GitHub Pages](https://github.com/yapb/docs/actions/workflows/deploy-pages.yml/badge.svg?branch=master)](https://github.com/yapb/docs/actions/workflows/deploy-pages.yml)

This is documentation for the YaPB bot for the Counter-Strike game.

* English: https://yapb.github.io/docs/en/
* Russian: https://yapb.github.io/docs/ru/

## Contributing

If you have time and interest, you can contribute to the documentation right here — fixes and new translations are welcome via pull requests.

## Development

The site is built with [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/).

```bash
npm install
npm run dev
```

Content lives in `src/content/docs/en` and `src/content/docs/ru`. Deploys to GitHub Pages automatically on push to `master`.
