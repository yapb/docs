---
title: "Configuring the Bot"
---

Bot CVARS are located inside `yapb.cfg` and parsed on every level change. The new config will be applied on map change or by issuing `exec addons/yapb/conf/yapb.cfg` inside the server console.

CVARs can be changed on the fly by typing them into the console.

See the following sections for detailed configuration reference:

- [Bot CVARs](\/docs\/en/configuring/cvars/) -- Full reference of all ~110 bot CVARs
- [Map-Specific Config](\/docs\/en/configuring/map-config/) -- Per-map configuration files
- [Custom Config](\/docs\/en/configuring/custom-config/) -- Hard-coded settings in `custom.cfg`
- [Difficulty](\/docs\/en/configuring/difficulty/) -- Fine-tuning bot difficulty levels
- [Weapons](\/docs\/en/configuring/weapons/) -- Weapon buy flags, priorities, and economics
- [Localization](\/docs\/en/configuring/localization/) -- Language support and translations
- [Customization](\/docs\/en/configuring/customization/) -- Chat, voice, and appearance customization
- [Bot Usage](\/docs\/en/configuring/botusage/) -- In-game menus, commands, and bot management
