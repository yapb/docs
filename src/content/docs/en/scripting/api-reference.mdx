Current module API: **3.6** (`kBotModuleApiMajor` / `kBotModuleApiMinor` in `inc/module.h`). Check it at runtime with `yb_get_api_version()` / `yb_api_at_least()` (see [Scripting](/docs/en/scripting/)).

Conventions below:

* Bot `index` is the player entity index (1..maxplayers). Always validate with `yb_is_user_bot()`.
* Node indexes are graph indexes, or `YB_INVALID_NODE_INDEX` (`-1`) when none.
* Entity indexes use `YB_INVALID_ENTITY_INDEX` (`0`) when none.
* `Float:origin[3]` params are world coordinates.

| Value | Meaning |

### `YBChatMode`

Who may chat for a bot (`yb_set_bot_chat()` / `yb_get_bot_chat()`).

| Value | Meaning |
|-------|---------|
| `YB_CHAT_INVALID` `-1` | Invalid bot |
| `YB_CHAT_AUTO` `0` | Core AI decides when and what to say |
| `YB_CHAT_MANUAL` `1` | Core AI is silent, plugin controls all chat |
| `YB_CHAT_OFF` `2` | No chat at all |

### `YBChatSource`

Who produced a chat message in `yb_chat_pre` / `yb_chat_post`.

| Value | Meaning |
|-------|---------|
| `YB_CHAT_HUMAN` `0` | Human player |
| `YB_CHAT_BOT` `1` | Bot (core AI) |
| `YB_CHAT_PLUGIN` `2` | Plugin (via `yb_bot_say()`) |

## Helper stock

```c
stock bool:yb_api_at_least (const major, const minor)
```

Returns true when the loaded module API is at least `major.minor`. Decode manually if needed: `major = version >>> 16`, `minor = version & 0xFFFF`.
