---
title: "Решение проблем"
description: "Чиним самые частые проблемы YaPB: боты не заходят, нет графа, меню, модуль AMXX, плагины."
---

Большинство проблем укладывается в несколько типичных случаев. Найдите ниже свой симптом.

## Боты не заходят на сервер

1. Введите `yb version` в консоли сервера. Если команда неизвестна - бот установлен неверно, повторите [установку](/docs/ru/getting-started/installation/) (плагин MetaMod против отдельного `liblist.gam`).
2. Введите `yb list`. Если пусто - проверьте квоту: `yb_quota` должна быть больше `0`.
3. Если `yb_join_after_player` равен `1`, а людей на сервере нет - боты ждут специально. Зайдите в команду сами или поставьте `0`.
4. После смены карты боты перезаходят через `yb_join_delay` секунд (по умолчанию `5`). Подождите немного, прежде чем делать выводы.
5. На локальном сервере убедитесь, что `maxplayers` не урезал слоты так, что мест не осталось.

## Боты зашли, но стоят

- `yb_freeze_bots` должен быть `0`, `yb_dont_shoot` - `0` (если вы не включили их специально).
- `yb_ignore_enemies 1` заставляет ботов бегать по целям без боя - это только для особых настроек.

## Нет графа для карты

1. По умолчанию YaPB сам скачивает недостающий граф (`yb_graph_url`), а если не вышло - строит его сам (`yb_graph_analyze_auto_start` по умолчанию `1`). Обоим нужно несколько рестартов раунда, лучше с парой ботов в игре.
2. Проверьте, что есть: `yb graph stats` и `yb graph fileinfo`.
3. Если пусто - смотрите консоль: ошибки скачивания (нет сети, сборка без TLS, пустой `yb_graph_url`), см. [Установка графов](/docs/ru/waypointing/#установка-графов).
4. Граф всегда можно построить самому - см. [Редактирование графов](/docs/ru/waypointing/).

## Не открываются меню бота

- На локальном сервере нажмите `=` (или клавишу из `yb_bind_menu_key`).
- На выделенном сервере нужен удалённый доступ: задайте `yb_password` и `yb_password_key` в консоли сервера, затем введите `setinfo <ключ> <пароль>` в своей игровой консоли. См. [Управление ботами на выделенном сервере](/docs/ru/configuring/botusage/#управление-ботами-на-выделенном-сервере).
- Для команд графов дополнительно нужен `yb g acquire_editor` (а потом `yb g release_editor`).

## Не работают фишки скорборда (пинг, аватары, фейковые игроки)

Им нужна помощь от игровой DLL. На **выделенном** сервере пропишите в `addons/yapb/conf/custom.cfg`:

```ini
EnableFakeBotFeatures = i'm confident for what i'm doing
```

затем перезапустите сервер (custom.cfg применяется только при рестарте). На локальном сервере работает из коробки. Подробнее: `yb_enable_query_hook`, `yb_show_latency`, `yb_show_avatars`.

## Не грузится модуль AMXX (`yapb_amxx`)

1. В `amxx modules` модуль `YaPB API` должен быть в статусе running. Если там ошибка - откройте логи AMXX, модуль пишет точную причину.
2. Чеклист: `yapb_amxx` включён в `modules.ini`; `yapb_amxx.dll` / `yapb_amxx_i386.so` лежит в `addons/amxmodx/modules/`; сам бот установлен в `addons/yapb/bin/` (модуль грузит его оттуда в рантайме); `yapb.inc` соответствует версии модуля.
3. Полная настройка: [Скриптинг](/docs/ru/scripting/).

## Chat AI молчит

1. В `amxx plugins` должен работать `yapb_chat_ai.amxx`, а в `amxx modules` - **оба** модуля `yapb_amxx` и `easy_http`. Модуль EasyHttp берётся из [релизов AmxxEasyHttp](https://github.com/Next21Team/AmxxEasyHttp/releases) и ставится отдельно.
2. Проверьте `yb_chat_ai_url`, `yb_chat_ai_model` и `yb_chat_ai_api_key` (ключ нужен только для эндпоинтов с авторизацией).
3. Поставьте `yb_chat_ai_debug 1`, повторите, затем читайте `addons/amxmodx/logs/yapb_chat_ai.log` - там конфиг, причины блокировок, HTTP-коды и ответы.
4. Помните про правила срабатывания: по умолчанию сообщение человека должно начинаться с имени бота (`yb_chat_ai_addressed 1`).

## Не срабатывает Takeover

1. Плагину нужен **ReAPI** (а значит ReHLDS + ReGameDLL) - без него плагин даже не скомпилируется и не запустится.
2. Вы должны быть мертвы и spectate'ить бота-**тиммейта** от первого лица (`eye`) или в свободной погоне (`chase`), затем нажать `N` (или `E` при `yb_takeover_use_key 1`).
3. VIP-ботов, уже занятых, stale- и мёртвых ботов взять нельзя. Лимиты на раунд - из `yb_takeover_max_uses`.
4. При `yb_takeover_log 1` причины попадают в `yapb_takeover.log`.

## Где искать ошибки

- Вывод консоли сервера при старте карты.
- Логи бота: `addons/yapb/logs/`.
- Логи AMXX: `addons/amxmodx/logs/` (ошибки загрузки модуля, рантайм-ошибки плагинов, `yapb_chat_ai.log`, `yapb_takeover.log` при включённом логировании).
