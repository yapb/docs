---
title: "Пользовательский файл конфигурации"
---

Пользовательский файл конфигурации, который позволяет вам изменить некоторые захардкоженные вещи в коде бота.

Он находится в `addons/yapb/conf/custom.cfg`.

:::note
Все изменения в этом файле вступают в силу только после перезапуска сервера.
:::

:::note
Ключи могут находиться как внутри своих секций (как в поставляемом конфиге), так и на верхнем уровне файла — принимаются оба варианта.
:::

## Доступные настройки

| Настройка | Описание |
|-----------|----------|
| `C4ModelName` | Задаёт пользовательское название для модели C4, для серверов, которые заменяют модель C4 на свою собственную. По умолчанию это `c4.mdl` (путь модели опущен), поэтому если вам нужно использовать `models/mybomb/mybomb.mdl`, вы должны указать `mybomb/mybomb.mdl`. |
| `AMXParachuteCvar` | Задаёт пользовательское название CVAR для управления парашютом. Существуют различные плагины, которые управляют парашютами (AMX Parachute, AMX Parachute Lite и т.д.), вы можете указать нужный CVAR здесь. |
| `CustomCSDMSpawnPoint` | Задаёт пользовательское название класса точки возрождения для CSDM модов, которые добавляют свои точки возрождения, отличные от `info_player_start` и `info_player_deathmatch`. Таким образом, боты смогут присоединиться к игре без стандартных сущностей возрождения. |
| `CSDMDetectCvar` | Задаёт CVAR для обнаружения CSDM мода, если он активирован в игре. |
| `ZMDetectCvar` | Задаёт CVAR для обнарушения зомби мода. |
| `ZMDelayCvar` | Задаёт CVAR, который определяет время до начала любого игрового режима. |
| `ZMInfectedTeam` | Определяет команду, в которой находятся заражённые игроки. Допустимые значения: `T`, `CT`. |
| `EnableFakeBotFeatures` | Определяет, должны ли быть включены поддельные функции (такие как поддельное время, поддельный SID (аватар), фейковый пинг) в коде бота на выделенном сервере. По умолчанию это выключено. Чтобы включить его, вы должны предоставить переменную со значением: `i'm confident for what i'm doing`. Его значение не влияет на локальный сервер. |
| `CheckConnectivityHost` | Задаёт имя хоста, к которому бот будет пытаться подключиться для проверки доступности сети и включения функций скачивания/загрузки графов. Поддерживается необязательный суффикс `:port` (по умолчанию 80), например `raw.githubusercontent.com:443`. |
| `DisableLogFile` | Отключает любую запись в лог-файлы. Все ошибки и предупреждения просто отправляются в консоль сервера. |
| `DisableSpawnControl` | Отключает соблюдение лимитов точек возрождения при создании ботов и управлении квотой, позволяя использовать пользовательские редакторы спавнов. |
| `UnlockThinkFPS` | Позволяет управлять частотой мышления бота (тикрейте) через квар `yb_think_fps`. По умолчанию тикрейт бота зафиксирован на внутреннем значении, а `yb_think_fps` игнорируется. |

## Конечные точки базы графов

Секция `GraphDatabase` содержит конечные точки за `@алиасами` кваров `yb_graph_url` / `yb_graph_url_upload` (см. [Квары](/docs/ru/configuring/cvars/)). Измените их здесь, чтобы перенести базу графов без пересборки бота.

| Настройка | Описание |
|-----------|----------|
| `GraphGithubDownload` | База скачивания за алиасом `@github` квара `yb_graph_url` (CDN raw по https). |
| `GraphRussiaDownload` | База скачивания за алиасом `@russia` квара `yb_graph_url` (sourcecraft по https). |
| `GraphWorkersUpload` | База загрузки за алиасом `@workers` квара `yb_graph_url_upload` (cloudflare worker по https). |
| `GraphRussiaWorker` | База загрузки за алиасом `@russia` квара `yb_graph_url_upload` (копия на yandex worker по https). |
| `GraphLegacyBase` | База за алиасом `@http` / `@legacy` (legacy-сервер по обычному http). |
| `GraphLegacyUpload` | База загрузки, используемая как fallback без TLS для `@workers` и `@russia`. |

При скачивании к базовому URL добавляется путь `graph/<map>.graph`; при загрузке граф-файл отправляется POST-запросом на базовый URL как есть. Автоматический сбор графов доступен только по https.
