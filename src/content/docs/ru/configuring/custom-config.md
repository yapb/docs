---
title: "Пользовательский файл конфигурации"
---

Пользовательский файл конфигурации, который позволяет вам изменить некоторые захардкоженные вещи в коде бота.

Он находится в `addons/yapb/conf/custom.cfg`.

:::note
Все изменения в этом файле вступают в силу только после перезапуска сервера.
:::

:::note
Ключи могут находиться как внутри своих секций (как в поставляемом конфиге), так и на верхнем уровне файла - принимаются оба варианта.
:::

## Подключение

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `CheckConnectivityHost` | `google.com:443` | Задаёт имя хоста, к которому бот будет пытаться подключиться для проверки доступности сети и включения функций скачивания/загрузки графов. Поддерживается необязательный суффикс `:port` (по умолчанию 80), например `google.com:443`. |

## Игра

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `C4ModelName` | `c4.mdl` | Задаёт пользовательское название для модели C4, для серверов, которые заменяют модель C4 на свою собственную. По умолчанию это `c4.mdl` (путь модели опущен), поэтому если вам нужно использовать `models/mybomb/mybomb.mdl`, вы должны указать `mybomb/mybomb.mdl`. |
| `AMXParachuteCvar` | `sv_parachute` | Задаёт пользовательское название CVAR для управления парашютом. Существуют различные плагины, которые управляют парашютами (AMX Parachute, AMX Parachute Lite и т.д.), вы можете указать нужный CVAR здесь. |

## Моды

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `CustomCSDMSpawnPoint` | `view_spawn` | Задаёт пользовательское название класса точки возрождения для CSDM модов, которые добавляют свои точки возрождения, отличные от `info_player_start` и `info_player_deathmatch`. Таким образом, боты смогут присоединиться к игре без стандартных сущностей возрождения. |
| `CSDMDetectCvar` | `csdm_active` | Задаёт CVAR для обнаружения CSDM мода, если он активирован в игре. |
| `ZMDetectCvar` | `zp_delay,zp_on` | Задаёт CVAR для обнаружения зомби мода. |
| `ZMDelayCvar` | `zp_delay` | Задаёт CVAR, который определяет время до начала любого игрового режима. |
| `ZMInfectedTeam` | `T` | Определяет команду, в которой находятся заражённые игроки. Допустимые значения: `T`, `CT`. |

## Функции

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `EnableFakeBotFeatures` | `no` | Определяет, должны ли быть включены поддельные функции (такие как поддельное время, поддельный SID (аватар), фейковый пинг) в коде бота на выделенном сервере. По умолчанию это выключено. Чтобы включить его, вы должны предоставить переменную со значением: `i'm confident for what i'm doing`. Его значение не влияет на локальный сервер. |
| `DisableLogFile` | `no` | Отключает любую запись в лог-файлы. Все ошибки и предупреждения просто отправляются в консоль сервера. |
| `DisableSpawnControl` | `no` | Отключает соблюдение лимитов точек возрождения при создании ботов и управлении квотой, позволяя использовать пользовательские редакторы спавнов. |
| `UnlockThinkFPS` | `no` | Позволяет управлять частотой мышления бота (тикрейтом) через квар `yb_think_fps`. По умолчанию тикрейт бота зафиксирован на внутреннем значении, а `yb_think_fps` игнорируется. |

## Стены режимов

Секция `ModeWalls` поддерживает плагины ограничения карты (например AMXX "Mode 2x2"), которые перекрывают части карты сущностями-стенами при низком онлайне.

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `ModeWallClassname` | `test_effect` | Classname сущностей-стен, создаваемых плагином (по умолчанию `test_effect`). Боты считают сущности с этим classname и solid bbox препятствиями для поиска пути. |

## Бот

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `BlockedClientCommands` | `lastinv` | Список клиентских команд, разделённых запятыми или пробелами, которые ботам никогда не должны принудительно выполняться. Значение по умолчанию `lastinv` предотвращает краш `SelectLastItem` в игровой DLL из-за устаревшего указателя на оружие. |

## Конечные точки базы графов

Секция `GraphDatabase` содержит конечные точки за `@алиасами` кваров `yb_graph_url` / `yb_graph_url_upload` (см. [Квары](/docs/ru/configuring/cvars/)). Измените их здесь, чтобы перенести базу графов без пересборки бота.

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `GraphGithubDownload` | `https://raw.githubusercontent.com/yapb/graph/refs/heads/master` | База скачивания за алиасом `@github` квара `yb_graph_url` (CDN raw по https). |
| `GraphRussiaDownload` | `https://sourcecraft.dev/api/file/yapb/graph` | База скачивания за алиасом `@russia` квара `yb_graph_url` (sourcecraft по https). |
| `GraphWorkersUpload` | `https://graph-worker.yapb.workers.dev` | База загрузки за алиасом `@workers` квара `yb_graph_url_upload` (cloudflare worker по https). |
| `GraphRussiaWorker` | `https://d5d5lttn6kg3uqou32ei.g4vq2kuy.apigw.yandexcloud.net` | База загрузки за алиасом `@russia` квара `yb_graph_url_upload` (копия на yandex worker по https). |
| `GraphLegacyBase` | `http://yapb.jeefo.net` | База за алиасом `@http` / `@legacy` (legacy-сервер по обычному http). |
| `GraphLegacyUpload` | `http://yapb.jeefo.net/upload` | База загрузки, используемая как fallback без TLS для `@workers` и `@russia`. |

При скачивании к базовому URL добавляется путь `graph/<map>.graph`; при загрузке граф-файл отправляется POST-запросом на базовый URL как есть. Автоматический сбор графов доступен только по https.
