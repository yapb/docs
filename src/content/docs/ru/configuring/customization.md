## Настройка чата

Вы можете создать новую базу чата для вашего языка или изменить существующую. Файлы чата находятся в папке `addons/yapb/conf/lang` и называются `**_chat.cfg`, где `**` — это код языка (например, `en_chat.cfg`). Загружается файл для языка, установленного в `yb_language`.

Боты могут писать сообщения в чат в зависимости от ситуации: закладка бомбы, убийство врага, атака тиммейтов и т.д.

:::note
Если конфиг чата отсутствует или повреждён, чат ботов отключается автоматически (`yb_chat` сбрасывается в `0`).
:::

### Формат

Каждая секция чата находится на верхнем уровне файла — это блок с ключевым словом `raw`: его строки берутся дословно, по одному сообщению на строку. Порядок сообщений рандомизируется самим ботом.

:::note
Устаревший вариант с единственным корневым блоком `Chat`, оборачивающим все секции, по-прежнему принимается — старые конфиги продолжают работать. Новые файлы следует писать в плоском формате.
:::

```ini
raw Killed {
   %v, you're no match for me!
   Sorry, %v. You got in my way.
   That'll teach you, %v!
}
```

### Плейсхолдеры

| Плейсхолдер | Описание |
|-------------|-------------|
| `%v` | Вставляет ник последнего игрока, убитого ботом |
| `%f` | Вставляет ник игрока с наибольшим количеством фрагов |
| `%t` | Вставляет ник случайного живого тиммейта |
| `%e` | Вставляет ник случайного живого врага |
| `%s` | Вставляет ник игрока, которому бот отвечает (или игрока с наибольшим количеством фрагов) |
| `%m` | Вставляет имя текущей карты |
| `%d` | Вставляет название игры (`Counter-Strike`/`CS` или `Condition Zero`/`CZ`) |
| `%r` | Вставляет оставшееся время раунда в формате `мм:сс` |
| `%g` | Вставляет автора текущего файла графа |

В одном сообщении подставляется не более шести плейсхолдеров. Неизвестные маркеры остаются как есть.

### Секции чата

| Секция | Описание |
|---------|-------------|
| `BombPlant` | Сообщения, которые боты пишут после закладки бомбы |
| `Killed` | Сообщения, которые боты пишут после убийства врага. Используйте плейсхолдер `%v`, чтобы вставить ник убитого врага |
| `DeadChat` | Сообщения, которые боты пишут, когда они мертвы или находятся в режиме наблюдателя |
| `Welcome` | Сообщения, которые боты пишут при подключении к серверу |
| `TeamAttack` | Сообщения, которые боты пишут, когда по ним стреляет тиммейт |
| `TeamKill` | Сообщения, которые боты пишут, когда убили тиммейта |
| `Unknown` | Запасные ответы, используемые, когда ни одно ключевое слово не совпало с текстом чата (см. `Replies` ниже) |

Пример — когда бот убивает врага с ником "John Smith", он может написать "You're dead John Smith!", используя строку `You're dead %v!` из секции `Killed`.

### Ответы (Replies)

Блок `Replies` задаёт сообщения, которые боты пишут в ответ на чат игрока, если в нём содержится известное ключевое слово. Каждая группа ответов — это блок (имя произвольное) с одной или несколькими записями `key = "..."` и анонимным блоком `raw`, в котором перечислены ответы.

```ini
Replies {
   AIMBOT {
      key = "AIMBOT"
      key = "WALLHACK"

      raw {
         %s, are you cheating?
         Aimbots are cool, shut up %s!
         I saw %f peeking through walls. Coincidence? I think not.
      }
   }

   AGAIN {
      key = " AGAIN "

      raw {
         %s, things are always repeating - aren't they?
         Here we go again. Deja vu.
      }
   }
}
```

Вот как это будет выглядеть в игре:

```
John Smith: Bla bla bla aimbot
Ricardo Milos: John Smith, are you cheating?

Keanu Reeves: Bla bla bla again bla bla...
Tommy Vercetti: Here we go again. Deja vu.
```

Боты могут использовать эти ответы в случайном порядке. Ключевые слова сопоставляются с текстом чата без учёта регистра; заключите ключ в пробелы (например, `" AGAIN "`), чтобы он совпадал как целое слово.

:::note
Пишите ключи заглавными буквами — они сохраняются в верхнем регистре. В сообщениях игроков они могут быть написаны в любом формате.
:::

## Настройка голосового чата

YaPB поддерживает голосовой чат так же, как ZBot. Все пути к аудиофайлам голосового чата YaPB находятся в файле: `chatter.cfg`, который расположен в папке `addons/yapb/conf`.

:::note
Голосовой чат используется только при `yb_radio_mode` со значением `2`. Все изменения в этом файле вступают в силу только после перезапуска сервера.
:::

### Формат

Каждое событие находится на верхнем уровне файла — это блок с именем события голосового чата, содержащий имена звуковых файлов (без префикса `sound/` и расширения), по одному на строку. Также принимается скалярное значение через запятую:

:::note
Устаревший вариант с единственным корневым блоком `Chatter`, оборачивающим все события, по-прежнему принимается — старые конфиги продолжают работать. Новые файлы следует писать в плоском формате.
:::

```ini
RewritePath = sound/radio/bot

CoverMe {
   cover_me
   cover_me2
}

EnemyDown = enemy_down, enemy_down2
```

`RewritePath` задаёт папку, в которой расположены аудиофайлы голосового чата. По умолчанию это `sound/radio/bot`. В плоском формате он находится на верхнем уровне файла (в устаревшем варианте — внутри блока `Chatter`).

Отсутствующие звуковые файлы сообщаются в консоль. Если отсутствует более десяти файлов, голосовой чат отключается, и боты откатываются на стандартное радио (`yb_radio_mode` сбрасывается в `1`).
