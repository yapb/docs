---
title: "Конфигурация для карты"
---

Конфиги для карт хранят пользовательские CVARы. Имя файла — `<mapname>.cfg`, где "mapname" — это имя карты, для которой был создан этот конфиг, например, `de_dust2.cfg` для карты de_dust2. Этот файл находится в директории `addons/yapb/conf/maps`.

Вы можете использовать любые из [CVARов ботов](\/docs\/ru/configuring/cvars/) в этом конфиге. Он выполняется автоматически через команду движка `exec` при старте соответствующей карты.

По умолчанию YaPB не поставляет конфигов для карт — в директории `maps` лежит только заглушка `.gitkeep`. Создайте файл с именем вашей карты, чтобы переопределить на ней квары.

Пример `addons/yapb/conf/maps/fy_pool_day.cfg`:

```ini
yb_quota 12
yb_botbuy 0
```
