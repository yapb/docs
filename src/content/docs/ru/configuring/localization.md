Файлы локализации YaPB находятся внутри папки `addons/yapb/conf/lang`. Основная локализация находится внутри `**_lang.cfg`, где `**` — это код языка.

На данный момент YaPB поставляет пять языков:

- `en` -- Английский (встроенные исходные строки, `en_lang.cfg` не нужен)
- `ru` -- Русский
- `de` -- Немецкий
- `chs` -- Китайский (Упрощённый)
- `cht` -- Китайский (Традиционный)

Чтобы выбрать язык, вы должны использовать один из предложенных языковых кодов в качестве значения квара `yb_language`, или указать свой собственный, если вы создали новый конфиг с переводом на другой язык.

Вы можете изменить значение `yb_language` в `addons/yapb/conf/yapb.cfg`.

Также, помимо локализации основных вещей бота, таких как меню, всплывающие сообщения, текст в консоли и т.д., вы можете создать базу чата на вашем языке. Используйте `**_chat.cfg` для чата. Ники ботов общие для всех языков и лежат в `addons/yapb/conf/names.cfg` (объединены из старых по-языковых списков имён).

## Основная локализация

Чтобы перевести бота на ваш язык, создайте файл `**_lang.cfg` (можно использовать `ru_lang.cfg` в качестве шаблона).

Каждая запись находится на верхнем уровне файла: это именованный блок (имя произвольное) с двумя блоками `raw`: `Original` с английской исходной строкой и `Translated` с переводом. Строки внутри блоков `raw` берутся дословно и соединяются переводами строк, поэтому многострочные строки вроде меню переводятся построчно.

:::note
Устаревший вариант с единственным корневым блоком `Lang`, оборачивающим все записи, по-прежнему принимается — старые конфиги продолжают работать. Новые файлы следует писать в плоском формате.
:::

```ini
YMainMenuW {
   raw Original {
      \yMain Menu\w
      1. Control bots
      2. Features
      3. Fill server
      4. End round
      0. Exit
   }

   raw Translated {
      \yГлавное меню\w
      1. Управление ботами
      2. Функции
      3. Заполнить сервер
      4. Конец раунда
      0. Выход
   }
}
```

Строки сопоставляются по точному содержимому блока `Original` (имена записей не важны). Оба блока должны быть непустыми, иначе запись пропускается.

### Рабочий процесс с непереведёнными строками

Бот отслеживает строки, которые показывались во время игры, но не имеют перевода в загруженном языке. Доперевести перевод можно командами `yb debug`:

- `yb debug translate` -- показывает собранные во время игры непереведённые строки
- `yb debug translate write` -- дописывает собранные строки в языковой конфиг (предыдущий файл сохраняется в `.bak`), после чего заполните блоки `Translated`
- `yb debug translate reset` -- очищает список собранных строк

## Локализация чата

Вам просто нужно создать файл `**_chat.cfg` для чата ботов на вашем языке. Вы можете использовать файл `en_chat.cfg` в качестве примера.

Подробности см. в разделе [Персонализация](\/docs\/ru/configuring/customization/).

## Настройка ников

Ники ботов лежат в общем файле `addons/yapb/conf/names.cfg` (по одному нику на строку внутри блока `raw Names`). Чтобы настроить их, правьте этот файл напрямую — он действует для всех языков.
