Текущее API модуля: **3.6** (`kBotModuleApiMajor` / `kBotModuleApiMinor` в `inc/module.h`). Проверяется в рантайме через `yb_get_api_version()` / `yb_api_at_least()` (см. [Скриптинг](/docs/ru/scripting/)).

Соглашения:

* `index` бота - это индекс игрока (1..maxplayers). Всегда проверяйте через `yb_is_user_bot()`.
* Индексы точек - это индексы графа, либо `YB_INVALID_NODE_INDEX` (`-1`), если точки нет.
* Индексы сущностей - `YB_INVALID_ENTITY_INDEX` (`0`), если сущности нет.
* Параметры `Float:origin[3]` - мировые координаты.

## Enum

### `YBNodeFlag`

Битовые флаги, возвращает `yb_get_node_flags()`.

| Значение | Смысл |
|----------|-------|
| `YB_NODE_FLAG_BUTTON` `(1<<0)` | Рядом кнопка |
| `YB_NODE_FLAG_LIFT` `(1<<1)` | Лифт / подъёмник |
| `YB_NODE_FLAG_CROUCH` `(1<<2)` | Точка приседа |
| `YB_NODE_FLAG_CROSSING` `(1<<3)` | Перекрёсток |
| `YB_NODE_FLAG_GOAL` `(1<<4)` | Цель |
| `YB_NODE_FLAG_LADDER` `(1<<5)` | Лестница |
| `YB_NODE_FLAG_RESCUE` `(1<<6)` | Зона спасения заложников |
| `YB_NODE_FLAG_CAMP` `(1<<7)` | Кемперская точка |
| `YB_NODE_FLAG_NO_HOSTAGE` `(1<<8)` | Заложники избегают точку |
| `YB_NODE_FLAG_DOUBLE_JUMP` `(1<<9)` | Место для двойного прыжка |
| `YB_NODE_FLAG_NARROW` `(1<<10)` | Узкий проход |

## Хелпер

```c
stock bool:yb_api_at_least (const major, const minor)
```

Возвращает true, если загруженный API модуля не ниже `major.minor`. Вручную: `major = version >>> 16`, `minor = version & 0xFFFF`.
